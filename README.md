# Требования к веб-приложению «Магазин локальных фермерских продуктов»

## Общие требования
1. Приложение должно обладать интуитивно понятным пользовательским интерфейсом, адаптивным дизайном, а также обеспечивать удобный и быстрый доступ к каталогу товаров и корзине. 
2. Реализация формы оформления курьерской доставки (с выбором адреса и зоны) или базовая демо-интеграция (заглушка) с API сторонних сервисов доставки (например, Яндекс.Доставка или Самокат) для демонстрации концепта взаимодействия с внешними системами. 
3. Поддержка минимально необходимых версий браузеров (Chrome >= 60, Firefox >= 55, Edge >= 79, Safari >= 12).

## Функциональные требования

### Отображение товаров
- Пользователь должен видеть список продуктов с возможностью добавления продукта в корзину.
- Каждый товар должен содержать: название, параметры (вес/объем), пищевую ценность (БЖУ), состав и срок годности.
- Реализовать сортировку и фильтрацию списка: по алфавиту и по категориям (мясо, рыба, молочная продукция, овощи и т.д.).
      
### Информационные страницы
- Раздел с описанием магазина и информацией о месте изготовления продуктов (фермах).
- Раздел с графиком работы и картой/списком доступных зон доставки по городу.

### Основной каталог поддерживает базовые операции
1. Выбор товара для добавления в корзину и изменение его количества (включая удаление). 
2. Переход к подробной карточке товара для просмотра всех характеристик.
3. Автоматический пересчет итоговой стоимости в корзине в зависимости от объема/веса заказанного товара и его количества. 
4. Форма ввода данных получателя (ФИО, телефон) и точного адреса доставки с валидацией введенных данных. 
5. Реализация всплывающих уведомлений (Toast-уведомлений) или отдельной панели для информирования пользователя о статусных событиях (например: «Заказ успешно принят», «Заказ передан в доставку»). 
6. Сохранять статус корзины и количества товаров при закрытии окна и возобновлять сессию при следующем открытии.
7. **Избранное:** Возможность добавления товаров в список «Избранное» для отложенного спроса.

### Средства разработки 
- HTML
- JavaScript(React)
- CSS 
#### База данных
- PostgreSQL
# Детали страниц приложения

## Страница личного кабинета
- окно регистрации
- окно авторизации

### Главная страница
Главная страница должна содержать:
- название магазина;
- краткое описание магазина;
- кнопку перехода в каталог;
- краткую информацию о доставке.

### Страница каталога
Страница каталога должна содержать:
- список товаров в виде карточек;
- фильтр по категориям;
- поиск по названию;
- кнопку добавления товара в корзину;
- кнопку добавления товара в избранное.

### Страница товара
Страница товара должна содержать:
- изображение товара;
- название;
- описание;
- цену;
- вес или объём;
- состав;
- БЖУ;
- срок годности;
- поле выбора количества;
- кнопку «Добавить в корзину».

### Страница корзины
Страница корзины должна содержать:
- список выбранных товаров;
- количество каждого товара;
- цену за единицу;
- сумму по позиции;
- общую сумму заказа;
- кнопки удаления товаров;
- кнопку «Оформить заказ»;
- кнопку «Очистить корзину».

### Страница оформления заказа
Страница оформления заказа должна содержать:
- список товаров из корзины;
- итоговую сумму;
- форму с полями: имя, телефон, адрес доставки, комментарий;
- кнопку «Подтвердить заказ».

### Страница избранного
Страница избранного должна содержать:
- список избранных товаров;
- кнопку «Добавить в корзину» для каждого товара;
- кнопку удаления из избранного.

### Страница статуса заказа

Статусы заказа:
- заказ принят;
- заказ передан в доставку;
- заказ доставлен.

### Информационные страницы
Нужно предусмотреть страницы:
- «О магазине»;
- «Доставка».

Страница «Доставка» должна содержать:
- график работы;
- зоны доставки;
- условия доставки;
- контакты.
